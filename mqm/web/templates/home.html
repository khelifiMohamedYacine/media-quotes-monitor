What happens when I add a source?
  1. The system reads the site’s robots.txt and looks for a news sitemap or RSS feed (or uses the topic page / link you gave).
  2. The source is saved to config/sources.yaml and appears in the Sources table below.
  3. A background job collects its articles since {{ default_start }}, keeps only those about the war, and extracts quotes that are verified word-for-word.
  4. From then on the daily run checks it automatically. Sites that refuse automated access are added as Inbox only: save their articles into ./inbox and use “Import ./inbox pages”.
